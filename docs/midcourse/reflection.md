Throughout this project, I relied heavily on AI tools to help with planning, problem-solving, and implementation. I primarily used cloud-based AI assistants to generate solutions, explain concepts, and suggest implementation approaches. However, I quickly learned that the quality of the output depended heavily on the context I provided.

One of the biggest lessons was that AI often makes assumptions when important details are missing. For example, when I asked how to store data without specifying my project's requirements, it suggested using either JSON files or SQLite as a local database. In another case, it assumed I was building the project with plain HTML and JavaScript, while I was actually using the Vite framework. Had I not corrected these assumptions, I could have ended up implementing solutions that were unnecessary or incompatible with my project. This taught me the importance of clearly defining the technology stack, project scope, constraints, and the role I wanted the AI to take before asking for assistance.

AI was most helpful when working in environments where it had access to the project files and codebase. Instead of guessing, it could analyse the existing structure, understand dependencies, and provide suggestions that were relevant to the actual project. This significantly reduced incorrect assumptions and improved the quality of its recommendations.

There were also times when AI slowed me down. If I asked it to implement a feature without specifying the exact file or function to modify, it would often rewrite multiple files or generate additional code that was not required. Reviewing and undoing these unnecessary changes sometimes took longer than writing the code myself.

One practice that noticeably improved my workflow was asking the AI to create a step-by-step implementation plan before writing any code. By reviewing each step individually, I could verify the approach, make informed decisions, and implement only the changes I needed. Finally, I found that maintaining up-to-date project documentation after completing each feature made future AI interactions much more effective. Clear documentation provided both me and the AI with an accurate understanding of what had already been implemented, what remained to be done, and the reasoning behind previous design decisions.
